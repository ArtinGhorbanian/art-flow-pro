# Support

Use the repository's question template for setup and usage questions, and the
bug template for reproducible defects. Search existing documentation and issues
first.

Include the version, operating system, browser, command used, expected behavior,
and sanitized error text. Never attach `.env`, database, resume, project-content,
or credential files.

Security issues follow [`SECURITY.md`](SECURITY.md). Licensing and publication
questions follow
[`docs/RIGHTS_AND_RELEASE_STATUS.md`](docs/RIGHTS_AND_RELEASE_STATUS.md).

No response-time commitment, paid support plan, production SLA, or external
support address is currently offered.
