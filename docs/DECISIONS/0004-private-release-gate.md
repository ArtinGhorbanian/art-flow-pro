# ADR 0004: Private release gate

- Status: Accepted
- Date: 2026-08-08

## Context

The supplied folder had no authorship, assignment, license, contributor, or Git
history evidence. Primary-source checks also found active software businesses
using the requested ArtFlow Pro and AIONEX names.

## Decision

Prepare a professional repository and private engineering release, but do not
make it public, apply an exclusive AIONEX copyright claim, or publish commercial
launch material until provenance and name clearance are complete.

## Consequences

Engineering work remains reviewable and recoverable without creating a public
rights or confusion risk. Public discoverability, a social preview, commercial
calls to action, and public release promotion remain intentionally blocked.
